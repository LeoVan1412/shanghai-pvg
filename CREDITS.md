# Credits / 致谢

Map design, clean-room data model, generation code and validation workflow:
**LeoVan**.

Geographic data: © OpenStreetMap contributors, distributed under ODbL 1.0 and
downloaded as Geofabrik regional extracts.

Building footprints: Overture Maps Foundation buildings theme, ODbL 1.0.
Upstream contributors represented by the selected release include
OpenStreetMap contributors, Esri Community Maps contributors, Microsoft Global
ML Building Footprints, Google Open Buildings, and Qian Shi et al. East Asian
Buildings (CC BY 4.0).

Bathymetry and ocean depth shading: GEBCO Compilation Group (2024) GEBCO 2024
Grid (doi:10.5285/1c44ce99-0a0d-5f4f-e063-7086abc0ea0f), placed in the public
domain under the GEBCO Terms of Use with source acknowledgement required, via
the cloud-optimized GeoTIFF mirror published by Alex Leith on Source Cooperative.

Routing engine: OSRM Backend contributors.

Official statistical and administrative sources are listed individually in
[`DATA_SOURCES.md`](DATA_SOURCES.md), `SOURCE-REGISTRY.json`, and
`OFFICIAL-POPULATION-SOURCES.json` in the release ZIP.

No data files, demand surfaces, population groups, compiled tiles, foundations,
collision indexes, routes, code or meshes from Kronifer's Shanghai map are used
as inputs to this rebuild.

Apple Maps and AutoNavi may be used only for visual quality assurance. No
proprietary imagery, coordinates, vector data, textures or geometry from those
services may be copied into the project.
