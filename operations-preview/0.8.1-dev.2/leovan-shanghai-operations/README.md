# Shanghai Operations / 上海多制式运营

这是上海 PVG 地图的独立运营增强模组。它不会改写地图本体或 3D 地标，可单独停用。

## v0.8.1-dev.2 开发预览状态

这是供源码审阅的开发候选，不是已经通过 Railyard 审核或全面运营验收的正式版本。默认线路规划流程继承 v0.8.0；自动接轨、动态越行和可选站台离站保护仍为开发接口，不会在安装后自动接管全网，也没有面向普通玩家的完整启用流程。

2026-10-01，在实际安装的 Subway Builder 1.7.2 中，本候选通过约两小时游戏时间的接轨/越行专项：原 43 条线路、228 列车基础上，临时快车原生上线 8 列；5 次待避中，3 次独立核验了快车车尾清空后同一慢车实际发车。原两列 T1 分别有 33/44 条测试后的真实到站记录，原车零超时移除/零缺失，有限采样车体重叠为 0。另 2 次待避没有充分连续证据，不计成功。

出口安全仍需整列车长＋25 m；跨入下一真实区间时，还需精确路径连续、实际到站及非空车体证据。没有移走原车、清除原生预留或放宽 900 s 停滞阈值。正式撤销后原轨道/轨道组/线路结构/库存保持不变；退出测试并冷读备份后，九个完整数据层核对一致。

完整多小时/完整载客周转、扩大线网与多种站型的验收仍待完成。决策耗时不能当作游戏帧率保证。本候选保持 `publishReady=false`；请使用独立备份测试，不覆盖正式安装或玩家进度。预览不包含测试驱动、游戏原生代码、个人存档或原始日志，也不包含新版预建网络存档。

v0.8.0 是本地测试候选版，流程为“选线路 → 看停站/地图/配车预览 → 应用为新增服务”。应用不再仅写建议，而是调用游戏原生寻路建立独立运营服务、设置实际停站和发车计划；原线路及原列车保留。普通/快车/急行与跨线直通分开选择，可组合使用。

默认面板只显示停站摘要和配车建议，逐站清单、速度/间隔与费用明细按需展开。已应用服务保留真实停站和设置过的目标间隔；面板分开显示计划列数与实际上线列数，不把发车计划当作已经出库。

自动站型按实际车站、独立线路走廊和既有股道判断。普通站默认双线，同走廊的快慢车不被重复算成多条线路。具备股道条件的站型会写入游戏原生车站类型；尚缺股道或通过线的车站明确标为“待改造”，不会假装已经建成，也不会自动拆建原站。车站建设模板仍保留在开发接口中，自动接轨施工不属于本候选版已完成的能力。

配车助手考虑原生往返时间、站台最短长度、现有库存及其他线路占用，给出目标间隔、编组、列数、容量与运行费用。建议基于目标间隔，不是实测需求预测。应用优先使用库存；购买需要明确点击带价格的按钮，先检查共享轨道班次容量，再按原生价格购买缺少的车厢。旧型号库存会幂等迁移到五档新型号，数量守恒，不凭空补车或扣钱。

撤销只移除本次新增服务并恢复由它管理的站型，保留原线路及其他方案的站型需求；购入车厢保留库存，不作虚假退款。如果该服务后来被手动修改，撤销会停止并提示，避免覆盖新修改。撤销凭据随线路/车站存档保存。

PVG 原生线路预览不再自动暂停全网；用户主动暂停或继续的选择始终保留。规划索引按基础设施变化更新，不随着每一帧列车移动重建；地图预览沿实际轨道几何绘制，新增预览图层可清除。新服务仍受游戏信号、站台、车场及班次容量约束，不能保证共享轨道总有额外发车容量。

若默认起点站台被原列车占用，会尝试让新服务从另一空闲端点开始；仅循环平移既有闭合停站序列，不改变区间连接、原车位置或信号占用。没有可用端点时仍须等待原生调度，不强制塞入列车。

## 历史版本

v0.7.0 的“保存线路方案”只保存建议；已由 v0.8.0 的真实服务应用替代。

v0.6.0 改为“线路优先”：玩家不再在建设每座车站时选择普通站、越行站、换乘枢纽或综合枢纽。先在原生路线编辑器选择沿线车站，再在本模组选择线路等级和普通/快车/急行/直通方式；模组会按线路交汇数量、端点属性和快慢车待避间隔自动生成整条线路的站型规划。规划写入线路存档，既有车站不会被强拆。

v0.5.1 移除 v0.4.2 曾加入的 `+10`、`+20` 待购车厢按钮和对应界面监听，购车窗口恢复为游戏原生样式。五档车辆、模块化建站与存档兼容逻辑不受影响。

v0.5.0 把原来的长表单改成接近《狂热运输》思路的模块化建造器。车站用途、线路等级、股道数、站台布局、咽喉、折返和存车线都改为可直接点击的卡片；中央轨道示意图实时标出停车股道和无站台通过线。线路运营移到独立标签，不再和建站参数混在同一页。精确角度和站台长度仍保留在折叠区。

v0.4.1 修正原生建造器仍显示其他车辆模组全部类型的问题。在上海 PVG 地图内，游戏原生“轨道类型”菜单和本模组面板都只显示五档：轻运量 80、中运量 120、高运量 160、城际铁路 200、高速铁路 300（km/h）。离开 PVG 并载入其他城市时，会恢复其他模组的车辆目录，不影响它们在其他地图使用。

v0.4.0 将轨道和配套车辆从七档收敛为上述五档。旧存档读取时会临时注册兼容别名，载入后自动映射到这五档并马上把别名从选择器移除；不会删除线路、车站或轨道。载客量和成本采用偏轻松的游戏平衡，高等级车辆仍有成本差异，但运营费不会随速度成倍暴涨。

v0.3.2 在 v0.3.1 的大型线网性能保护基础上修复 PVG 存档的地图资源路径。模组从 Railyard 当前注册城市地址解析每次启动动态分配的本地 HTTP 端口，将存档恢复出的旧 `map://PVG` 瓦片源切换到当前可用的 `/PVG/{z}/{x}/{y}.mvt` 服务；仅在实际修复旧源时把错误视角恢复到上海。诊断快照只在地图载入后的 0/1/5 秒记录，不进行常驻轮询。

v0.3.0 把多股道建造改为“用途预设优先”：选择普通中间站、快慢车越行站、同台换乘枢纽、市域快慢车枢纽、综合始发终到站或综合直通枢纽后，模板、咽喉、折返线、存车线和建议运行模式会一并配置。高级设置仍可单独调整。

本版同时保留 v0.2.1 的上海存档菜单入口兼容：当游戏以旧的 `PVG` 地址读取存档时，在读取开始前跳转到 Railyard 的完整地图标识。不会改写存档文件，也不会改变其他城市的入口。

## 已实现

- 线路优先的自动站型规划：普通站、越行站、换乘枢纽、综合枢纽由整线条件自动判断，无需逐站选择。
- 2 股道单岛、4 股道双岛、6 股道三岛、8 股道四岛模板。
- 4/6/8 股道越行模板，急行通过线不生成车站站台。
- 六种建站用途预设与模板开发接口；默认面板以线路规划为主。
- 双端梯形咽喉、双端剪式渡线、独立站后折返轨和 0/1/2 条存车线。
- 多个原生站台组件自动归入同一物理车站组，支持同站换乘和同台换乘建模。
- 普通、快车、急行三个停站模式，可与直通叠加；往返两侧共用停站集合，保留端点与换乘锚点。
- 轻运量 80、中运量 120、高运量 160、城际铁路 200、高速铁路 300 五种轨道与配套车辆（km/h）。
- 上海 PVG 原生建造器的全局类型菜单也仅保留上述五项；其他地图会恢复外部车辆模组目录。
- 低等级车辆可进入部分更高等级轨道；高运量与城际可跨线，300 km/h 高速铁路保持独立。
- 偏轻松成本平衡：单车厢容量依次为 180 / 260 / 340 / 190 / 120 人；车辆基础小时运营费依次为 160 / 220 / 300 / 420 / 600，单节附加小时费用为 12 / 16 / 20 / 25 / 30。
- 进路审计：检查车辆/轨道不兼容，以及多线路共用咽喉冲突区。

进路审计是规则检查，不是接管游戏调度的动态联锁系统；封锁咽喉及单线对向避让须另做游戏内验收。

## 使用

进入上海 PVG 地图后，点击顶部的“Network”图标：

1. 先用游戏原生路线编辑器创建线路并选择沿线车站。
2. 在“上海线路规划”中选择线路，选择普通/快车/急行；如需要，再选兼容且共用端点的直通线路。
3. 点击“地图预览”查看走向；逐站列表实心圆为停靠，空心圆为通过，点站名可定位。
4. 检查配车建议，点击“应用为新增服务”。原线路照常运行，不被替换。
5. 如需补充车厢，选择刚生成的服务并确认报价；无空余轨道容量时不会先扣购车费。
6. 选择生成的服务可“撤销这次方案”。

“站体朝向”只用于旋转车站几何，不代表行车方向。单股道车站模板始终为双向共用，不保存固定方向；列车的运行方向由具体路线和进路决定。

## 兼容性说明

Subway Builder 1.7.0 的公开建造界面最多提供四线布局。本模组的 6/8 线车站由多个原生 1/2/4 线站台组件组成，并通过物理车站组表现为同一枢纽。模板生成使用带版本保护的内部建造接口；若接口不存在，模组只注册车辆和车站类型，不会修改存档。

停站、车辆与跨线方案通过原生寻路及班次检查后才会落地。路径失败会清理本次新服务，不改原网。直通要求闭合往返线路、兼容车辆和唯一共用端点；换乘站靠近不代表轨道已接通。跳站不等于自动越行，动态待避和完整接轨改造仍需进一步开发与验收。

车辆载客量和速度是游戏平衡值，不代表具体车型或官方运营承诺；线路曲线、渡线、车站和坡度仍会限制实际速度。
